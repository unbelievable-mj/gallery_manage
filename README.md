# 滑图 · SwipeGallery

以「快速过筛」为核心的 Android 本地相册管理工具。打开相册，**上滑扔掉、下滑归档、左滑跳过**，全程显示处理进度，每一步都能撤销。

---

## 安装

打开发布页下载最新的 `SwipeGallery-v*.apk` 直接安装：

```
https://github.com/unbelievable-mj/gallery_manage/releases/latest
```

首次安装需要在系统设置里允许「安装未知来源应用」。新版本可直接覆盖安装，不会丢数据。

## 功能

### 媒体库

- 图片 / 视频分栏浏览，三列网格
- 按相册筛选，只处理指定相册
- 排序：拍摄时间 / 修改时间 / 文件大小 / 文件名 / 视频时长，可升降序

### 滑卡过筛

核心交互。点开任意一张进入全屏，直接开始处理：

| 手势 | 作用 |
| --- | --- |
| **上滑** | 移入回收站 |
| **下滑** | 保留（可在设置里改为移动到指定相册） |
| **左滑** | 跳过，处理下一张 |
| **右滑** | 回到上一张 |
| **点击** | 视频播放 / 暂停 |

顶部实时显示「已处理 / 总数」，误操作可连续撤销。

### 视频播放

真实播放，不是首帧预览。进度条可拖拽也可点击跳转，显示当前时间与总时长。

### 回收站

删除的内容先进入**应用自己的回收站**，可以随时取回 —— 恢复是瞬时的，文件根本没被动过。确认不要了再彻底删除。

设备支持系统回收站时，应用里也能看到并取回其中的内容。

### 存储统计

总占用、图片与视频占比、**回收站占用**（这部分仍在占磁盘），以及按相册的占用排行，一眼看出是哪个相册最占地方。

### 设置

- **预加载张数**：滑到某张时提前解码后面几张，默认 3。调高更顺滑，代价是内存占用
- **默认排序**：打开图库时的排序方式
- **下滑落点**：保留在原相册，或移动到指定相册

### 其他

- 滑到下一张时预加载已就绪，没有空白帧
- 删除只在内存里记账，退出时统一提交，不会逐张弹窗打断
- 未捕获异常会把堆栈写到本地，下次启动直接显示在屏幕上（没有 adb 时便于排查）

## 权限

| 权限 | 用途 |
| --- | --- |
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` | 读取图片与视频 |
| `READ_MEDIA_VISUAL_USER_SELECTED` | 部分授权：只处理你选中的内容 |
| `MANAGE_MEDIA` | 可选。开启后删除不再逐次弹系统确认框 |
| `POST_NOTIFICATIONS` | 可选。后台任务进度通知 |

应用不联网，所有数据都留在本机。

## 技术

Kotlin · Jetpack Compose · Material 3 · Hilt · MediaStore · Room · DataStore · Media3 ExoPlayer

多模块单向依赖：`app → feature/* → core/data → core/model`。UI 层不直接接触 `ContentResolver`，所有媒体操作都收敛在数据层 —— 这是撤销能力能够成立的前提。

目标平台 Android 11+（minSdk 30 / targetSdk 37）。
